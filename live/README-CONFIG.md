# Configuración de credenciales

El archivo `config.js` está ignorado por Git para proteger tus credenciales.

## Primera vez en una máquina nueva:

1. Copia el ejemplo:
   ```
   cp live/config.example.js live/config.js
   ```
2. Abre `live/config.js`
3. Reemplaza los valores con tus credenciales reales

## Dónde obtener las credenciales:

- **Supabase URL y Key:**
  supabase.com → tu proyecto → Connect → App Frameworks
- **WhatsApp:**
  Tu número con código de país (`521` + 10 dígitos, sin espacios ni guiones)
